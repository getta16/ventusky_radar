# ฝนเฉลี่ยในพื้นที่ (Areal rainfall)

เว็บคำนวณปริมาณฝนเฉลี่ยเชิงพื้นที่ของจังหวัด ลุ่มน้ำหลัก และลุ่มน้ำย่อย (สทนช.) บนแผนที่อากาศ Ventusky

- **Open-Meteo API**: เฉลี่ยฝนจากจุดกริดภายในขอบเขต (เลือกแบบจำลองได้ · วันฝน 07–07 น. หรือ 00–24 น.)
- **ภาพ Ventusky เทียบสี**: จับภาพชั้นฝน 3 ชม. แล้วแปลงสีเป็น มม. แบบเดียวกับ `trackflood/scripts/ventusky_rain.py` (ต้องอนุญาตแชร์แท็บใน Chrome/Edge)

ข้อมูล: ฝน [Open-Meteo](https://open-meteo.com/) (CC BY 4.0) · แผนที่ [Ventusky](https://www.ventusky.com/) · ขอบเขตลุ่มน้ำ สทนช. (ONWR) · ขอบเขตจังหวัด
ค่าที่ได้เป็นการประมาณจากแบบจำลอง ใช้เพื่อการติดตามเบื้องต้นเท่านั้น
